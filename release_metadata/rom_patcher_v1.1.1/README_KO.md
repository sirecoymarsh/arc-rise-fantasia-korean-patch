# v1.1.1 원클릭 ROM 패처 검증 자료

- `PATCH_MANIFEST.json`: 722개 VCDIFF 항목, 원본/출력 해시, 런타임 패치 계약
- `RELEASE_MANIFEST.json`: 최종 배포 스테이징 736개 매니페스트 대상 파일
- `RAY_STONE_FIELD_PATCH.json`: `btl_usual.vol`의 별도 필드 오브젝트 이름 `レイストーン`을 `레이 스톤`으로 수정한 바이트 제한 증거
- `TARGETED_SEMANTIC_PROOF.json`: 최종 이미지의 레이 스톤 수정 및 케이지 상점 번역 포함 증거
- `VALIDATION.json`: 722/722 독립 출력 해시 검사, 독립 부팅, ZIP 추출, GUI 실행, Defender 검사 결과
- `ArcRiseFantasia-Korean-ROM-Patcher-v1.1.1.zip.sha256`: GitHub Release 첨부 ZIP 체크섬

릴리스에는 완전한 원본 또는 패치 게임 이미지가 없으며 VCDIFF 델타만 포함됩니다. 의미 번역·교정은 Codex 내부 모델만 사용했습니다. 레이 스톤 전투 표시와 케이지 상점은 최종 이미지에 포함되었음을 정적으로 증명했으며 실제 화면 재확인은 수동 검증 항목으로 남겨 두었습니다.
