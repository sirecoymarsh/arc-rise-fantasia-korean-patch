# 번역 작업 정책

- 원문: 일본어 (`ja-JP`)
- 번역문: 한국어 (`ko-KR`)
- 음성: 일본어 원본 유지
- 번역·교정·윤문·용어 통일: **Codex 내부 모델과 Codex 내부 하위 에이전트만 사용**
- 금지: Gemini, DeepL, Google Translate, Papago 및 그 밖의 외부 번역 API·외부 생성 모델
- 외부 웹 자료는 파일 포맷·도구 문서와 고유명사 표기 검증에만 사용할 수 있으며, 번역문 생성에는 사용하지 않는다.
- 제어 코드, 서식 지정자, 스크립트 키, 바이너리 구조, 아카이브 엔트리 이름은 번역하지 않는다.
- 원본 RVZ는 읽기 전용으로 보존하며 직접 덮어쓰지 않는다.
