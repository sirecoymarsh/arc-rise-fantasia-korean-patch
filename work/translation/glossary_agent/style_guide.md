# 《아크 라이즈 판타지아》 한국어화 문체 가이드 초안

## 1. 적용 범위와 번역 원칙

- 의미 기준은 **일본판 원문(JP)** 이다. 북미판/영어판 표기는 고유명사의 철자 의도를 추정하는 보조 자료일 뿐, 내용·말투·설정 용어를 대체하는 번역 원문이 아니다.
- 번역문·교정문은 **Codex 내부 모델의 문맥 추론만으로 작성**한다. Gemini, DeepL, Google Translate, Papago 및 기타 외부 번역 모델/API를 호출하거나 그 결과를 초안으로 가져오지 않는다.
- 입력 기준은 BSCR 문자열 영역을 정정한 `work/catalog/text_v2/text_catalog.json`이다: 84,761개 레코드, 29,777개 고유 원문. v1의 바이트코드 오검출 18,568개는 근거에서 제외한다.
- 본 파일과 `glossary.csv`는 초안이다. 대량 번역에 들어갈 때는 초안의 중간 확신 항목을 먼저 음성·연속 대사·메뉴 화면에서 확인한 뒤 해시를 고정한다.
- 텍스트는 안정 ID 단위로 소유하되, 번역은 장면·화자·튜토리얼·아이템 레코드처럼 **완전한 의미 단위**를 읽고 작성한다. 동일 일본어라도 문맥이 다르면 한국어가 달라질 수 있다.
- 개발용 문자열, 맵 초기화 라벨, 스캐너 오검출, 더미 데이터는 표시 여부가 확정되기 전까지 본문 번역 대상과 분리한다.

## 2. 표기 우선순위

1. `glossary.csv`의 `high` 항목
2. 일본판 게임 안에서 반복 확인되는 전체 이름·고유 호칭
3. 마블러스 공식 일본어 표기
4. 일본어 음성으로 확인되는 발음
5. 카타카나 음역 또는 한자 의미 번역
6. 해외판 표기(참고 전용)

한 항목에 충돌이 있으면 일본판 원문과 음성을 우선한다. 번역자가 임의로 해외판 개명을 가져오지 않는다.

## 4. 캐릭터 말투

화자 판별이 확정된 장면 묶음 안에서 적용한다. 이름이 대사 안에 나왔다는 이유만으로 해당 인물의 말투를 적용하지 않는다.

### 장면마다 관계와 수신자를 다시 판정

- 아래 인물별 말투는 **고정 템플릿이 아니라 보조 기준**이다. 어떤 인물의 첫 등장 장면에서 확인한 태도·존대·호칭·종결어를 이후 장면에 자동 승계하지 않는다.
- 새 장면이 시작될 때마다 `화자 → 실제 수신자 × 현재 관계 × 스토리 시점 × 상황`을 다시 판정한다. 같은 화자라도 상대와 관계 변화에 따라 반말/존댓말, 호칭, 명령 강도와 거리감이 달라져야 한다.
- 3인 이상 장면에서는 매 대사의 실제 수신자를 이름·호칭, 질문과 응답, 행동 묘사, 끼어들기, 화제 전환, 등장·퇴장으로 추적한다. 직전 상대의 말투를 다음 상대에게 그대로 이어 붙이지 않는다.
- 수신자가 불명확하면 원문에 없는 `너`, `당신`, 특정 이름을 임의로 보충하지 말고 한국어에서도 자연스러운 생략이나 집단 표현으로 모호성을 보존한다.
- `당신`은 일본어 `あなた/あんた/お前`의 기본 대응어가 아니다. 친밀·적대 관계에서는 `너/네/널`, 이름·직함, 주어 생략을 우선 검토하고, 공식적 거리감이 실제로 필요한 장면에서만 사용한다.
- 니콜의 `~슴다/~임다`처럼 인물 고유 말버릇은 화자 확인이 끝난 대사에만 적용한다. 동일 장면의 라르크·리피아·사쥬 등 다른 화자에게 전염시키지 않는다.
- 배치 경계나 동일 원문 재사용 때문에 장면 문맥이 끊기면 앞뒤 장면과 화자 슬롯을 복원한 뒤 번역한다. 복원하지 못한 상태에서 첫 용례의 번역을 전역 복사하지 않는다.

### 라르크

- 기본: 거칠지만 이해가 빠른 젊은 남성의 반말. `俺`, `～だ`, `～だろ`, `～じゃねぇ`의 추진력을 살린다.
- 동료에게는 `~야/~지/~잖아/~거든`, 군·공식 상대에게는 상황에 맞춰 존댓말 또는 군대식 보고체.
- 욕설은 원문 강도만큼만 쓴다. `くそ`는 보통 `젠장`, 감정이 약하면 `쳇`.
- 지나치게 양아치식 비속어나 현대 인터넷 은어를 덧붙이지 않는다.
- 근거 예: `ARF-A2385F3F1F65324D0489`의 `俺たちは…知ってるよな？`.

### 리피아

- 기본: 차분하고 부드러운 여성 반말. `～わ`, `～のよね`, `～かしら`를 매번 기계적으로 여성 종결어로 옮기지 말고 `~해`, `~거야`, `~일까`, `~네`로 자연스럽게 조절한다.
- 설정 설명은 또렷하고 단정하게, 감정 장면은 짧은 숨과 말줄임표를 살린다.
- 신관·디바 같은 과도한 고어체를 상시 부여하지 않는다.
- 근거 예: `ARF-4BB3D3139C86A805F304`의 `ええ、わかるわ`.

### 알스

- 기본: `僕`, `キミ`를 쓰는 온화하고 교양 있는 청년. 동년배에게 부드러운 반말, 공적 연설과 신하에게는 절제된 문어적 표현.
- 친절함과 왕자다운 책임감을 유지하되 지나친 존댓말 캐릭터로 만들지 않는다.
- 설득 장면은 논리적이고 침착하게 쓴다.
- 근거 예: `ARF-572E4C1131386CF61D48`의 `キミが…僕らは…`.

### 아델

- 기본: 또렷한 여성 반말. 친밀함, 불안, 질투, 의존이 급격히 오가는 감정선을 보존한다.
- 라르크에게는 친밀한 반말, 교단·공식 장면에서는 정중체를 쓴다.
- 감정 폭발을 원문보다 더 악의적으로 만들거나 순화하지 않는다.
- 근거 예: `ARF-4786930F00EAC9C95A93`의 `私がラルクにとって…`.

### 니콜

- 기본: 라르크를 `형님`이라 부르는 젊은 부하. `～ッス`는 `~슴다/~임다` 계열을 사용하되 모든 문장을 동일 종결어로 찍지 않는다.
- 긴 설명에서는 자연스러운 해요체를 섞어 가독성을 확보하고, 긴장하거나 허세를 부릴 때 `~슴다` 비중을 높인다.
- 말버릇을 오타처럼 보이게 만들지 않는다.
- 근거 예: `ARF-52D661DBDBEACCEDF408`의 `了解っス！`.

### 세실

- 기본: 작고 활기찬 자칭 용사. 힘찬 반말, 짧은 감탄, 자신만만한 과장을 살린다.
- 어린 캐릭터의 직설성을 살리되 유아어를 과잉 사용하지 않는다.
- `勇者`는 `용사`, 자칭 `セシル様`은 문맥에 따라 `이 세실 님`처럼 허세를 드러낼 수 있다.
- 근거 예: `ARF-869E388E78DBC5EFD415`의 `正義の勇者セシル様、参上！`.

### 사쥬

- 기본: 능글맞고 화려하며 일부러 여성적인 어미와 장난스러운 억양을 쓰는 성인.
- `～ネ`, `～ワ`, `♪`의 분위기는 `~네`, `~란다`, `~인걸♪` 등으로 살리되 캐릭터를 조롱하는 비하 표현을 만들지 않는다.
- 원문의 성적 농담·플러팅은 강도를 유지한다.
- 근거 예: `ARF-719751668162EBDBECAF`의 `もてる男はつらいわネ♪`.

### 오이겐

- 기본: 절제된 군인·참모형 해라체. `~다`, `~군`, `~하도록`, `~하라`를 중심으로 한다.
- 상관·공식 상대에게는 격식체, 동료에게도 감정을 과장하지 않는다.
- 고어체 `~하노라`는 신적 존재와 구분하기 위해 쓰지 않는다.
- 근거 예: `ARF-5EC3FFE9FCFD979FF006`의 `何度も言わせるな。私はオイゲンだ`.

### 레슬리

- 기본: 노련한 정치 지도자의 자신감. 공적 장면은 격식 있는 `~습니다`, 사적 장면은 절제된 `~해/~군`.
- 가벼운 유혹·농담과 의장으로서의 권위를 모두 살리며 일방적인 존댓말 캐릭터로 고정하지 않는다.
- 화자 메타데이터가 부족한 장면은 연속 대사로 화자를 검증한 뒤 적용한다.

### 바이스·호제아·로그레스/신적 존재

- 바이스: 황제다운 단호한 해라체. 감정이 흔들려도 품위를 잃는 현대 비속어를 쓰지 않는다.
- 호제아: 종교 지도자의 정중하고 장중한 어조. 지나친 사극체는 피한다.
- 로그레스·신적 존재: `我/汝`는 `나/그대`, 예언·명령은 `~하라/~하리라`를 제한적으로 쓴다. 매 문장을 `~노라`로 끝내지 않는다.

## 5. 전투·메뉴 용어

### 능력치와 자원

- `HP`, `MP`, `SP`, `AP`, `RP`, `WP`, `EXP`, `ATK`, `DEF`, `MGC`, `RES`, `SPD`, `LUK`, `LV`는 영문 약어를 유지한다.
- 원문의 전각 알파벳은 한국어 텍스트에서 반각 ASCII로 정규화하되, 제어 코드와 글꼴 폭 검증 후 적용한다.
- 약어를 문장마다 `공격력`, `방어력` 등으로 풀어쓰지 않는다. 튜토리얼에서 최초 설명이 필요할 때만 병기한다.
- 화폐 `リコ`는 `리코`로 쓴다.

### 속성

- 불 / 물 / 바람 / 땅 / 얼음 / 번개 / 빛 / 어둠 / 무속성
- 합성 설명은 `빛+어둠 속성 피해`처럼 짧게 쓴다.
- `無属性`은 `무속성`; `비속성`, `속성 없음` 혼용 금지.

### 범위와 효과 문장

- `単体` → `단일 대상`
- `範囲` → `범위`, `範囲内` → `범위 내`
- `全体` → `전체`
- `直線` → `직선`
- 기본 템플릿: `단일 대상에게 불 속성 피해`, `범위 내 대상의 HP를 중간 회복`.
- `追加効果：` → `추가 효과:`. 콜론 뒤 용어는 glossary와 동일하게 쓴다.
- `確率で` → `일정 확률로`; 수치가 있으면 추측하지 말고 원 수치를 유지한다.
- `僅かに／大きく／大幅に`는 `소폭／크게／대폭`으로 단계 차이를 보존한다.

### 상태 구분

- `状態異常`(혼란·맹독·침묵·석화·속박·마비·질병·수면) → `상태 이상`.
- `状態変化`(능력 상승/하락 및 강화·약화 계열) → `상태 변화`.
- 두 범주를 모두 `상태 이상`으로 합치지 않는다. 회복·해제 효과의 기계적 범위가 달라진다.
- `戦闘不能` → `전투 불능`, `瀕死` → `빈사`, `スタン` → `스턴`.
- `静寂`은 효과상 주문 봉쇄 문맥이므로 `침묵`, `足止め`는 이동/행동 제한 문맥이므로 잠정 `속박`.

### 명령과 AI 작전

- 공격 / 방어 / 도주 / 훔치기
- 알아서 / 격파 우선 / 광소술 우선 / 광소술 금지 / 회복 우선 / SP 보존
- `温存優先`은 설명상 SP를 쓰지 않는 작전이므로 단순 `온존 우선`이 아니라 `SP 보존`.

## 6. 마법·특수기·아이템 명명법

- 카타카나 고유 기술명은 원칙적으로 음역한다: `ブレイズ` → `블레이즈`, `ファイアシェル` → `파이어 셸`.
- 설명적 한자 기술명은 짧고 힘 있는 한국어 이름으로 옮긴다. 두 글자 한자명이 한국 한자음으로도 자연스러우면 `뇌명`, `광망`, `빙아`처럼 유지한다.
- 한자음이 뜻을 흐리거나 어색하면 의미 번역을 우선한다: `碧壁` → `푸른 장벽`.
- 동일 레코드에 기본 광소술명과 증폭/연계명이 함께 있을 수 있으므로 서로 합치지 않는다.
- 아이템 계열 접두·접미를 유지한다: 리퀴드, 퀵, 차지, 레스트, 젬, 파편, 비약, 타로.
- 장비 고유명은 신화·역사적 원형이 명확할 때 통용 한국어 표기를 우선하고, 불확실하면 일본어 음가를 기준으로 한다.
- 더미 아이템과 테스트 기술은 표시 여부가 확정되기 전까지 번역 본문과 분리한다.

## 7. 문장부호·줄바꿈·레이아웃

- 일본어 `。`는 제거하거나 한국어 마침표로 바꾼다. 대사에서는 화면 톤에 맞춰 마침표를 생략할 수 있으나 한 장면 안에서 일관되게 한다.
- 일본어 `、`를 무조건 쉼표로 옮기지 말고 한국어 호흡에 맞춰 삭제·재배치한다.
- `……`는 기본 말줄임표로 유지한다. `...`, `…`, `……`를 장면 안에서 섞지 않는다.
- `!?`와 `!!`는 원문의 감정 강도를 보존한다. 과잉 증폭하지 않는다.
- 원문 줄바꿈은 의미가 아니라 화면 배치일 수 있다. 전체 문장을 먼저 번역한 뒤 필드 수와 실제 폭에 맞춰 다시 나눈다.
- 한국어 조사나 용언을 다음 줄 첫머리에 홀로 남기지 않는다.
- 3줄 대사는 각 줄의 의미 덩어리를 맞추되, 원문과 정확히 같은 위치에서 줄을 끊을 필요는 없다.

## 8. 제어 코드와 보호 토큰

- `<$15>D4`, `<$13>03`, `<$19>00`, `<$0C>` 같은 토큰은 **바이트 의미를 검증하기 전 변경·번역·재정렬하지 않는다**.
- 숫자, `%`, 슬롯 번호, 속성 코드, 변수 코드는 원문 그대로 보존한다.
- 제어 바이트가 문자열 선두에 붙어 문자처럼 스캔된 사례가 있다. `C`, `G`, `*`, 숫자 같은 선두 문자가 실제 이름 일부인지 먼저 원시 바이트와 레코드 구조를 확인한다.
- `raw_hex`, `offset`, `capacity_to_nul`, `leaf_sha256`를 사용해 원본 일치 여부를 확인한 뒤 적용한다.
- 키·파일명·스크립트 라벨·개발자 주석은 표시 문자열로 입증되기 전 번역하지 않는다.

## 9. 존댓말·호칭

- `様`은 신분과 관계에 따라 `님/전하/폐하`로 문맥 번역한다. 이름 뒤에 항상 `님`을 붙이지 않는다.
- `殿下`는 `전하`, `皇帝`는 `황제`, `聖皇`은 고유 직위일 때 `성황`.
- 군 계급 `曹長`은 `상사`. `ラグーン曹長`은 `라군 상사`.
- `先生`은 교사·사범이면 `선생님`, 의사·학자는 상황에 따라 `박사님`.
- 니콜의 `アニキ`는 `형님`으로 고정한다.
- 가족 호칭은 화자 기준으로 자연스럽게 옮긴다. 일본어 접미사만 보고 관계를 추정하지 않는다.

## 10. 번역 금칙

- 해외판의 개명·대사 재작성·검열을 일본판 번역의 근거로 삼지 않는다.
- 반복 문자열을 소스 텍스트만으로 전역 치환하지 않는다.
- `状態異常`과 `状態変化`, `飛光艇`과 `飛空艇`, `光召術`과 `歌召術`을 합치지 않는다.
- 능력 수치, 범위, 대상, 확률, 속성, 회복 단계, 무효/내성의 차이를 자연스러움을 이유로 바꾸지 않는다.
- 원문에 없는 성별·관계·감정을 덧붙이지 않는다.
- 디버그/더미 문자열을 플레이어 노출 문자열로 확정하지 않는다.
- 제어 코드를 자연어처럼 번역하지 않는다.

## 12. 초안 동결 전 확인 대상

- `アルス`의 최종 한국어 표기(`알스`)와 음성 일치 여부
- `サージュ`의 최종 한국어 표기(`사쥬`)와 장음/원어 의도

- `聖地ノワーレ`, `パーセヴァル` 등 외래 고유명의 최종 음성 대조
- `足止め`가 이동 제한인지 행동 불능인지 전투 런타임에서 확인
