# 용어집·문체 가이드 근거 기록

## 1. 결론 요약

- BSCR 문자열 영역을 바로잡은 일본판 텍스트 카탈로그 `work/catalog/text_v2/text_catalog.json`의 **84,761개 레코드 / 29,777개 고유 원문**을 읽어 핵심 인물·세계관·지명·조직·전투 시스템·아이템·마법 표기를 정리했다.
- `glossary.csv`에는 **286개 초안 항목**이 있다. 각 행은 일본어 원문, 권장 한국어, 범주, 근거, 확신도, 금칙 표기, 빈도를 포함한다.
- `frequency.json`에는 각 용어의 정확 일치 레코드 수, 포함 레코드 수, 출현 수, 논리 경로 수, 표면별 분포, 최대 3개의 안정 ID 문맥이 있다.
- 번역과 교정안 작성에는 **Codex 내부 모델의 추론만 사용**했다. Gemini, DeepL, Google Translate, Papago 또는 다른 외부 번역 모델/API는 사용하지 않았다.
- 웹 확인은 번역문 생성이 아니라 마블러스의 일본어 공식 고유명사·세계관 사실 검증에만 제한했다.

### v1 → v2 정정 감사

- v1은 103,329개 레코드였으나 BSCR 헤더의 문자열 영역 경계를 바로잡은 v2에서 **바이트코드 오검출 18,568개**가 제거되어 84,761개가 되었다.
- 고유 원문은 30,836개에서 29,777개로 1,059개 줄었다.
- 기존 286개 용어 중 **v1에서 카탈로그 근거가 있었으나 v2에서 사라진 항목은 0개**다.
- 작품명 `アークライズ ファンタジア`는 두 버전 모두 추출 텍스트 출현 수가 0이며, 마블러스 공식 제품 페이지를 근거로 유지한다.
- 정확 일치 빈도가 바뀐 용어는 0개다. 포함 빈도만 달라진 항목은 아래 5개다.
  - `レイ`: 619 → 622
  - `ギルド`: 164 → 166
  - `クエスト`: 123 → 125
  - `メニュー`: 39 → 40
  - `アップ`: 95 → 97
- 인물명, 세계관 핵심어, 광소술·엑셀 액트·암 포스 등 핵심 시스템 용어의 근거와 권장 번역은 유지했다.

## 3. 공식 일본어 근거

### 마블러스 제품 페이지

[마블러스 《アークライズ ファンタジア》 제품 페이지](https://www.marv.jp/titles/cs/585/)에서 다음 사실을 확인했다.

- 일본어 정식 작품명과 Wii 일본판 품번 `RVL-P-RPJJ`
- 세계 이름 `フルヘイム`
- 별의 에너지 `レイ`
- `巫[ディーバ]`라는 설정 표기
- 주인공 `ラルク`, 소녀 `リフィア`
- `濁竜`, `竜災害`, `結晶化`가 핵심 세계 현상이라는 설명

이 페이지는 한국어 번역을 제공하지 않으므로, 사실·일본어 표기만 검증하고 한국어 표현은 Codex 내부 추론으로 작성했다.

### 마블러스 공식 캠페인 페이지

[공식 캐릭터 배너 목록](https://www.marv.jp/special/game/wii/arcrise/form/20040.html)에서 다음 일본어 캐릭터 표기를 확인했다.

`ラルク`, `リフィア`, `アルス`, `アデール`, `ニコル`, `セシル`, `サージュ`, `レスリー`, `オイゲン`, `ポーリャ`, `ルーニャ`, `骸使い`, `ヴァイス`.

이 목록은 `glossary.csv`의 핵심 인물 원문 철자를 고정하는 데 사용했다. 한국어 표기는 일본판 음가와 게임 내 문맥에서 별도로 결정했다.

## 5. 시스템 용어 근거

### `光召術` → `광소술`

- `Btl/btl_tutorial.vld`에서 MP를 소비하고 조합·증폭되는 전투 술법으로 반복 설명된다.
- `magic.bin`에서 불·물·바람·땅 및 파생 속성 기술의 이름/설명과 연결된다.
- `operation.bin`에서 `光召術優先`, `光召術禁止`가 별도 AI 작전으로 존재한다.
- 설정식 한자 조어를 짧게 보존하기 위해 `빛소환술`보다 `광소술`을 초안으로 고정했다.

### `エクセルアクト` → `엑셀 액트`

- 전투 튜토리얼에서 강력해 항상 쓸 수 없는 기술로 설명된다.
- 맵 스크립트에 메뉴 해금 알림이 있다.
- 고유 시스템명인 만큼 의미 번역하지 않고 음역한다.

### `アームフォース` → `암 포스`

- 튜토리얼 대사에서 “무기에 깃든 힘”으로 직접 설명된다.
- 무기를 사용해 해방하면 `ピース`로 꺼내 다른 무기에 조합할 수 있다.
- `ability.bin`에서 발동 확률, 무효화, 능력 효과가 실제 시스템 항목으로 확인된다.

### 상태 범주

`ability.bin`과 `item.bin`은 `状態異常`, `状態変化`, `能力値変化`를 서로 다른 효과 범위로 사용한다. 따라서 다음처럼 분리했다.

- `状態異常` → 상태 이상
- `状態変化` → 상태 변화
- `能力値変化` → 능력치 변화
- `戦闘不能` → 전투 불능

이 구분을 합치면 회복·무효 효과의 범위가 바뀌므로 기계 정확성 항목으로 취급한다.

### AI 작전

`operation.bin`의 이름/설명 쌍을 근거로 다음을 고정했다.

- `おまかせ` → 알아서
- `撃破優先` → 격파 우선
- `光召術優先` → 광소술 우선
- `光召術禁止` → 광소술 금지
- `回復優先` → 회복 우선
- `温存優先` → SP 보존
- `たたかう` → 공격

`温存優先`은 실제 설명상 SP 소비 행동을 하지 않는 작전이므로 직역보다 기능을 드러냈다.

## 7. 카탈로그 한계와 번역 시 위험

### 공용 스크립트 복제

맵 BSCR에는 여러 맵에 공통 코드·메시지가 복제되어 있다. 같은 장면이 19~32개 논리 경로에서 반복되는 사례가 있고, 공통 파티 가입 메시지는 200개가 넘는 경로에 존재한다. 따라서 원시 레코드 수는 실제 플레이어가 읽는 고유 문장 수가 아니다.

### 개발용 문자열

다음 부류는 표시 여부가 확인되기 전 번역 대상에서 분리한다.

- 맵 초기화·NPC 배치·카메라·포그 설정 라벨
- `ロケタイ`, `カット`, `PLACE`, `START`가 포함된 개발용 명령
- `テスト`, `ダミー`, 미완성 퀘스트 메모
- `_map_test*` 경로

### 제어 바이트 스캐너 잔재

`magic.bin`, `special.bin`, `chat.bin`에는 실제 제어 바이트가 문자열 첫 글자처럼 보이는 항목이 있다. 예:

- `2ヒール`
- `Cアルスのこと`
- `G...` 또는 `*...`가 붙은 기술명

선두 문자까지 이름으로 번역하지 말고 원시 바이트 구조를 확인해야 한다.

### 짧은 문자열 빈도 오염

단순 포함 집계에서 `レイ`는 `フレイア`, `レイバニッシュ`에도 걸릴 수 있다. `グラ` 같은 짧은 개체명도 복합 이름 안에서 과계수될 수 있다. 빈도는 우선순위와 문맥 탐색에만 사용하고, 번역 대상 ID 수로 사용하지 않는다.

### 이름과 화자

이름이 대사에 포함되었다고 그 인물이 말한 것은 아니다. 캐릭터 말투 적용은 화자 명령·인접 이름 레코드·연속 장면으로 검증한다.

## 9. 산출물 관계

- `glossary.csv`: 번역자가 직접 적용할 용어·금칙 표기 테이블
- `style_guide.md`: 문체·기계 용어·보호 토큰 규칙
- `frequency.json`: 카탈로그 빈도와 안정 ID 문맥
- `evidence.md`: 공식 근거, 분석 방법, 한계와 재검증 목록

이 네 파일은 번역 본문이 아니라 대량 번역 전 동결할 용어집/문체 가이드 초안이다.
