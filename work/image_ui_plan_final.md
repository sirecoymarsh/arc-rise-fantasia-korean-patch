# Arc Rise Fantasia 이미지 기반 UI 한국어화 계획 (발견 전용)

## 이번 패스의 경계

- 실행한 것: 추출 파일과 기존 카탈로그를 이용한 경로/컨테이너/헤더 메타데이터 인벤토리.
- 실행하지 않은 것: 이미지 디코드·추출, 픽셀 수정, 재삽입, 게임 실행, 시각 검증, 최종 검증.
- 외부 웹·번역 모델·API 사용: 없음. 번역 문안은 이후 Codex 내부 모델로만 작성한다.
- 일본어 포함 여부가 `likely`/`unknown`인 항목은 파일명·컨테이너 의미에 따른 분류이며 픽셀 판독 결과가 아니다.

## 형식별 작업 방식

### WTMD
- 헤더의 캔버스 크기, GX 형식, 팔레트 형식, 이미지/팔레트 오프셋을 그대로 유지한다.
- C4/C8 등 팔레트 텍스처는 기존 팔레트 한도와 알파를 보존하고, 필요한 경우 동일 포맷 안에서 색을 재배치한다.
- 아틀라스는 셀 좌표와 UV 계약을 변경하지 않는다.

### CXD (LZ10 래퍼)
- 먼저 무변경 디코드/재압축 경로를 확정한 뒤 텍스트가 있는 WTMD 또는 내부 RTDP 멤버만 교체한다.
- 파일명, 내부 매직, 선언 압축 해제 크기, 정렬을 기록해 원래 CXD 위치로 되돌린다.

### RTDP/VOL
- `physical_archive + archive_identity + entry_index + member_name`을 재삽입 키로 사용한다.
- 중복 파일명(예: `e.wtm`, `reserved_file`)이 있으므로 이름만으로 교체하지 않는다.
- 기존 아카이브 정렬/간격과 예외적 템플릿을 보존한다.

### TPL / BRRES / ARC
- GX 텍스처 형식, 팔레트, 밉맵, BRLYT/BRLAN 리소스명과 애니메이션 참조를 보존한다.
- 타이틀의 `title_flear.tpl`은 글자 포함 여부가 확인될 때만 수정한다.

### BNR/WIBN
- 배너·아이콘 이미지, 애니메이션, 사운드와 메타데이터를 분리해 취급한다.
- 이미지 텍스트만 수정하고 IMET/IMD5 또는 WIBN 구조와 프레임 계약을 유지한다.

### SFD
- 구운 일본어가 확인될 때만 원본 해상도/프레임률/오디오 멀티플렉싱을 고정한 한국어 오버레이 또는 재인코딩을 검토한다.

## 후속 실행 순서 (현재는 미실행)

1. P0 후보를 무손상 디코드해 원본 100% 크기 콘택트시트를 만든다.
2. 각 이미지에 `Japanese=yes/no`, 번역 문자열, 글꼴, 정렬, 안전영역, 재삽입 키를 확정한다.
3. Codex 내부 모델로만 짧은 UI 문안을 번역하고 고유명사 표기와 일치시킨다.
4. 원본 캔버스에서 배경 복원 후 한국어 조판본을 만든다.
5. 형식별 동일 컨테이너에 재삽입하고 변경 허용 목록을 고정한다.
6. 모든 이미지 수정이 끝난 마지막 단계에서만 정적/시각/런타임 검증을 한 번에 수행한다.

## 마지막 검증에서 확인할 항목 (지금은 실행하지 않음)

- 변경 대상 외 파일 해시 불변, 각 컨테이너의 엔트리 순서/정렬/오프셋 계약.
- WTMD/TPL의 크기·GX 형식·팔레트·알파·아틀라스 셀 좌표.
- 100% 크기에서 일본어 잔존, 잘림, 번짐, 배경 복원 흔적, 대비 부족.
- 실제 게임의 부팅 경고, 채널/세이브 배너, 타이틀, 장소 입장, 카지노, 배틀 결과, 로딩, 엔딩 크레딧.
- SFD/ARC/BNR을 수정한 경우 애니메이션·오디오·레이아웃 참조 정상 여부.
