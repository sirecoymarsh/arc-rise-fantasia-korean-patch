# Arc Rise Fantasia (Japan) 한국어 패치

`RPJJ99` 일본판용 Riivolution 한국어 패치의 제작 소스, 번역 메모리, 빌드 도구 및 해시 결속 검증 자료입니다.

## 추가·변경 사항

원판(Wii 일본판 『아크 라이즈 판타지아』, 게임 ID `RPJJ99`) 대비 이 패치가 바꾸는 내용을 정리했습니다. 괄호 안은 근거(커밋 앞 7자, 파일 이름, 릴리스 태그)이고, 확실하지 않은 항목은 「(추정)」으로 표시했습니다.

> 이 README 아래쪽 「최종 배포본」은 v1.0 기준입니다. 최신 공개판은 **v1.1.3**(2026-08-23)이며, v1.0.1~v1.1.3의 저장소 변경은 아직 병합되지 않은 PR #1(`feat/one-click-installer`)에 있습니다.

### 번역 범위

- **번역 원문**: 일본판 원문(일본어)을 한국어로 옮겼습니다. 음성은 일본어 그대로입니다 (`work/project/translation_policy.md`). 번역·교정·윤문·용어 통일은 Codex 내부 모델만 썼고 외부 번역 API·생성 모델은 쓰지 않았습니다 (`release_metadata/PROVENANCE.json`).
- **규모**: 텍스트 레코드 84,761개에서 중복을 뺀 번역 메모리 29,777단위를 만들었고, v1.0 기준 번역 단위 29,986개·출현 85,597곳을 적용했습니다. 용어집 286개와 문체 가이드를 두었습니다 (`work/project/PROJECT_STATUS.md`, `PROVENANCE.json`).
- **본문·이벤트 대사**: 이벤트·맵 스크립트(BSCR 606개 묶음, 79,076곳)와 이벤트·맵 파일을 한국어화했습니다 (`PROVENANCE.json` `bscr_leaves`, `bscr_occurrences`).
- **시스템 텍스트**: 아이템·상점·특수기·도움말·몬스터 도감·어빌리티·채팅·드래곤·마법·작전·퀘스트·할 일(todo) 테이블을 고정 길이 슬롯 안에서 한국어화했습니다 (`work/final_system_table_application/replacement_catalogs/*.json`).
- **실행 코드 안 문구(`main.dol`)**: 초기 설정(컨트롤러 선택) 화면, 지도 범례, 카지노·코핀 미니게임, 화자·NPC 표시명 등 실행파일 안에 박힌 일본어를 한국어로 바꿨습니다. 처음에는 카탈로그에서 빠져 있다가 감사에서 발견해 추가했습니다 (`work/runtime_fix/runtime_ui_gap_audit.md`, `main_dol_translations.jsonl`).
- **전투 텍스트**: 몬스터 기본 표시명 270개, 보조 표시명 87회, 보스 부위명 3개, 몬스터 기술명 672회(고유 226개), 특수·보스 기술 80회(고유 79종), 전투 튜토리얼 376칸, 일반 전투 BTEM 14개 (`194254c`, `6cadde9`, `v1.0.4`, `v1.1.2`).
- **그림 글자(이미지)**: 경고문(`strapA/B_jp.wtm`), 타이틀(PRESS ANY BUTTON·New Game·Continue·로고 부제), 불러오는 중, 장소명 카드 37개, 블랙잭·포커 안내와 족보(`work/image_ui_final`), 메뉴·지도·무기 커스터마이즈·상점·퀘스트·몬스터 도감 그림 UI 68장·155개 표기(`v1.0.2`), 전투 그림 UI 12장·19개 표기(`v1.0.4`), 케이지 상점 그림 UI(`v1.1.1`), 엔딩 대사 이미지 23장(`work/runtime_fix/endroll_ui`).
- **Wii 시스템 부분**: HOME 메뉴 문구(`Hbm/home.csv`, `home_nosave.csv`)와 버튼 이미지 12개(`homeBtn.arc`: 닫기, Wii 메뉴로 등), Wii 메뉴 배너(`opening.bnr`)의 게임 이름을 「아크 라이즈 판타지아」로 바꿨습니다 (`work/runtime_fix/hbm_ko`, `opening_bnr_ko`).
- **지도**: 마을·필드 지도 아이콘 범례 15개(세이브 포인트·보물·다음 지도·세계 지도·사다리·여관·도구점·무구점·공방·양장점·길드·카지노·투기장·하모니 홀·현재위치, `v1.0.3`), 자동 이동 지도 지역 설명 36곳(`v1.0.4`).
- **영상**: 오프닝 영상 `Movie/RAY_OP_02.sfd`는 원본 그대로 쓰고, 대사 구간은 게임 엔진 자막 29개(`Map/map_d_hnk_00.cxd`)로 한국어 자막을 띄웁니다. 영상 21개의 음성을 전수 분류했습니다 (`release_metadata/rom_patcher_v1.1.2/SFD_DIALOGUE_CLOSURE.json`, PR #1 브랜치).
- **미번역으로 남긴 곳**: 오프닝 영상 안의 게임 제목 로고 아래 작은 일본어 부제 한 줄(영상 재인코딩 시 멈춤 문제 때문, `194254c`). Wii 메뉴 아이콘(`title.tpl`)은 높이가 3~4픽셀이라 한글을 넣지 않고 일본어 부제만 지웠습니다. 영어 로고·영어 부제는 장식으로 남겼습니다.

### 편의 기능

원판 게임 안에 새 기능을 넣지는 않았습니다. 설치 도구가 편의 기능입니다.

- **원클릭 Dolphin 설치(`설치하기.cmd`)**: Dolphin 사용자 폴더를 자동으로 찾고, 못 찾으면 폴더 선택창을 띄웁니다. 우리 패치 폴더와 XML만 설치·갱신하고 다른 Riivolution XML은 건드리지 않습니다. 변조된 패키지는 쓰기 전에 거부합니다 (`v1.0.1`, `587cd21`).
- **원클릭 ROM 패처(`ArcRiseFantasiaKoreanRomPatcher.exe`)**: 일본판 원본 RVZ/ISO를 골라 한국어가 들어간 별도 RVZ/ISO를 만듭니다. 원본은 고치지 않고, 게임 ID `RPJJ99`를 유지해 기존 세이브를 그대로 씁니다. Dolphin·Riivolution·PowerShell이 필요 없습니다 (`v1.1.0`, `9492266`).

### 단축키·조작

원판과 같습니다. 패치가 추가한 단축키는 없습니다.

### 화면·그래픽 개선

- **한글 글꼴**: 게임의 2바이트 글리프 영역(B0A1~F4FE)에 한글 1,370자를 직접 그려 넣는 전용 코드북을 만들었습니다. 원본 일본어 문자 2,227쌍은 보존 슬롯으로 남겼습니다 (`work/font/final_v3/codebook.json`).
- **이미지 보존 원칙**: 모든 이미지의 캔버스·GX 형식·팔레트·헤더를 유지하고 글자만 바꿨습니다 (`work/image_ui_final/reports/FINAL_REPORT.md`).
- 해상도·와이드 같은 화면 설정 변경은 없습니다.

### 버그 수정

- **고정 길이 테이블 손상(패치 제작 중 생긴 문제)**: 문자열 슬롯 길이를 실제보다 크게 잡아 뒤쪽 메타데이터를 0으로 덮던 문제를 고쳤습니다(`item.description_secondary` 82→81, `shop.name` 21→20, `special.description` 84→83, `help.description` 325→322, `monster_book.name` 36→35). 이 때문에 메타데이터 1,231바이트가 훼손되고 `item.bin` ID가 중복됐으며, Dolphin에서 무한 재시작이 났습니다(무한 재시작과의 관계는 (추정)). 원본에서 다시 빌드해 item ID 772개가 모두 유일함을 확인했습니다 (`51d97e5`).
- **와이번 영상 정지**: 재인코딩한 `RAY_OP_02.sfd`의 타임스탬프 역행(143회)·중복(97회) 때문에 48.5초 지점에서 멈췄습니다. 영상 교체를 빼고 원본을 쓰게 했습니다 (`194254c`).
- **NPC 반복 대화 시 오류(원판 코드 경로)**: 글자를 하나씩 띄우는 렌더러가 문자열 끝(NUL)·줄바꿈 바이트를 글자로 그리려다 잘못된 메모리를 연쇄로 읽던 문제를 실행 코드 수정으로 막았습니다 (`v1.1.0`, `NUL_GLYPH_GUARD_PATCH.json`).
- **ROM 패처 한글 경로 오류**: 출력 폴더에 한글이 있으면 WIT 오류 76으로 실패하던 문제를 영문 임시 작업 폴더로 고쳤습니다 (`v1.1.3`).
- **잔류 일본어 수정**: 지도 하단 「現在位置」 중복 표시(`v1.0.2`), 전투 시작 잔존 문자열 2곳(`v1.0.4`), 전투 필드 오브젝트 「レイストーン」→「레이 스톤」(`v1.1.1`), 「名称未設定」→「이름 미설정」(`v1.1.2`), 실제로 볼 수 있는 화자 자리표시 문구(`ないよ〜〜ん`→`없지롱~~`, `5bd4ab5`).
- **번역 교정**: 장면별 실제 대화 상대·관계·스토리 시점을 다시 판정해 131개 항목(실제 등장 358곳)을 고쳤습니다. 3인 이상 대화의 수신자 오판 127개, 첫 장면 말투가 뒤 장면·다른 인물로 번진 것 3개, 무관한 문장 의미가 복사된 오역 1개입니다 (`v1.0.5`, `7df4061`).

### 설치·제거 방식

- **원본 확인**: 일본판 원본 RVZ SHA-256 `4671E3E74EB664E441FA927FF6BE9FC06B7D4860782BC4CECCF7DBBB4108AAC5`이 기준입니다. ROM 패처는 722개 파일(게임 파일 721개 + `main.dol`)의 VCDIFF 차분만 담고 원본·완성 게임 이미지는 담지 않습니다.
- **A. 원클릭 ROM 패처(권장, v1.1.0 이후)**: ZIP을 완전히 풀고 exe 실행 → 원본 RVZ/ISO 선택 → 저장 위치와 RVZ/ISO 형식 선택 → 「한국어판 만들기」. 만든 파일은 Dolphin에서 바로 실행하거나 실기 USB 로더로 쓸 수 있습니다.
- **B. Wii 실기 Riivolution(v1.1.3)**: `payload/riivolution_sd` 안의 `arc_rise_fantasia_ko_full`·`riivolution` 두 폴더를 FAT32 SD 카드 루트에 복사 → 일본판 정품 디스크와 홈브류 채널·Riivolution으로 `Korean Full Text Patch`를 켜고 실행. 제거는 그 두 항목만 지웁니다 (`WII_RIIVOLUTION_INSTALL_KO.md`, PR #1 브랜치).
- **C. Dolphin Riivolution 오버레이(v1.0~v1.0.5)**: 원본 RVZ를 고치지 않고 Dolphin 사용자 폴더의 `Load`에 파일을 얹습니다. v1.0.1부터는 `설치하기.cmd` 더블클릭으로 설치하고, Dolphin에서 게임 우클릭 → Riivolution 패치로 시작합니다. 제거는 `Load\arc_rise_fantasia_ko_full`과 `Load\riivolution\arc_rise_fantasia_ko_full.xml`만 지웁니다(`riivolution` 폴더 전체를 지우면 다른 패치도 사라짐).
- **v1.0의 PowerShell 방식**: `Install-ARF-KO.ps1`가 원본 RVZ 해시와 패키지 해시를 확인하고 바꿀 파일을 백업·검증한 뒤 설치했으며, `Restore-ARF-KO.ps1`·`Verify-ARF-KO.ps1`로 복원·검사했습니다 (`release_metadata/`). v1.0.1에서 지속 백업·복원 상태를 없애고 위 원클릭 설치로 바꿨습니다.
- **지원 환경**: Dolphin(검증 설정 Vulkan, MMU 끔, Fast Disc Speed 끔), Wii 실기(Riivolution 또는 ROM 패처로 만든 ISO). 일본판 `RPJJ99`만 지원합니다.
